# Caso de Uso: UC11 - Registrar Logs

**Objetivo:** Registrar operações realizadas.

**Requisitos:** RF0012

**Atores:** Sistema, Usuário, Admnistrador

---

### Fluxo Principal

1. Usuário executa uma operação.
2. O sistema registra: Usuário; Data; Hora; IP de origem; Operação realizada.
3. O administrador consulta os registros.
