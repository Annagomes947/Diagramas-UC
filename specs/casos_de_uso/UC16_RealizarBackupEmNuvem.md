# Caso de Uso: UC16 - Realizar Backup em Nuvem

**Objetivo:** Realizar cópia de segurança dos dados.

**Requisitos:** RF1005

**Atores:** Administrador

**Condição de Entrada:** Acesso ao servidor cloud.

---

### Fluxo Principal

1. O administrador solicita backup.
2. O sistema gera cópia de: Cadastros; Consultas; Atendimentos; Prontuários; Logs.
3. O sistema envia os dados para a nuvem.
4. O sistema confirma a operação.
