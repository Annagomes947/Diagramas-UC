# Caso de Uso: UC14 - Consultar Histório Animal

**Objetivo:** Consultar histórico de vacinas, consultas, exames, datas dos atendimento.

**Requisitos:** RF1002

**Atores:** Tutor

**Condição de Entrada:** Usuário Autenticado.

---

### Fluxo Principal

1. O tutor acessa o sistema.
2. Seleciona um animal.
3. O sistema apresenta: Consultas; Vacinas; Exames; Datas dos atendimentos.
